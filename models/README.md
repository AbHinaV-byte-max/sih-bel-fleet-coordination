# models/

This directory stores trained ML artifacts for the Hybrid AI layer and Predictive Maintenance system.

## Contents

| File | Description |
|---|---|
| `training_data.csv` | Synthetic labeled dataset (generated by `scripts/generate_training_data.py`) |
| `priority_model.pkl` | Trained DecisionTreeClassifier for hybrid priority weighting |
| `validation_metrics.json` | Accuracy, feature importances, full decision tree rules |

## How to Regenerate

```bash
# Step 1: Generate synthetic training data (runs ~500 simulation episodes)
python scripts/generate_training_data.py

# Step 2: Train the DecisionTree and print validation accuracy
python scripts/train_priority_model.py

# Step 3: Restart server to load the new model
python -m uvicorn services.api_gateway.app:app --port 8000
```

## Design Rationale

- **max_depth=5**: Deliberately shallow for interpretability. Every prediction path
  can be expressed as ≤5 if-else rules, satisfying defense-grade explainability.
- **Safety**: The model ONLY adjusts `yield_priority_weight` BEFORE the deterministic
  `LocalConflictArbiter.arbitrate()` runs. It cannot override the arbiter's safety checks.
- **Fallback**: If no `.pkl` file exists, the system runs in rule-based fallback mode
  with zero degradation to collision-avoidance guarantees.

## Git Exclusion

`*.pkl` and `training_data.csv` are excluded from version control (see `.gitignore`).
They must be regenerated from source on each deployment.
